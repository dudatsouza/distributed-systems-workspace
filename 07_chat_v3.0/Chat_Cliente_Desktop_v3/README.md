# Chat_Cliente_Desktop_v3 (cliente)

Migrado do projeto NetBeans `SD-v4/Chat_Cliente_Desktop` para IntelliJ.

## Como rodar
1. Ative o **Serviço Desktop** no módulo `Chat_Middleware_Service_v3`.
2. IntelliJ: **File > Open** e escolha a pasta raiz `distributed-systems-workspace` (um projeto com todas as atividades).
3. No módulo `Chat_Cliente_Desktop_v3`, rode `pacote.Chat_Cliente_Desktop` (ou `pacote.FrmLogin`).
4. No login, preencha o nickname, a cor, o avatar e o **Servidor** (`localhost` ou o IP da máquina do middleware no laboratório).
5. Para abrir vários clientes: **Run > Edit Configurations > Modify options > Allow multiple instances**.

As imagens ficam em `src/images` (o IntelliJ copia para a saída junto com as classes).
